# rust-in-action

This repository holds code examples from the book "[Rust in Action](https://www.manning.com/books/rust-in-action)" by Tim McNamara, published by Manning.

The book's code repository is [here](https://github.com/rust-in-action/code).

The blog_os example is from the "[A Freestanding Rust Binary](https://os.phil-opp.com/freestanding-rust-binary/)" article in the "[Writing an OS in Rust](https://os.phil-opp.com/)" series by Philipp Oppermann.
